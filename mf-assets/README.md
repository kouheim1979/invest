# Asset Compass — Money Forward 資産管理補助アプリ

独立したブラウザアプリです。既存の投資アプリ・データファイルは読み込まず、変更しません。

公開URL: https://kouheim1979.github.io/invest/mf-assets/

## できること
- Money Forward ME入出金CSV、保有資産CSV、資産推移CSV、TSV・表の貼り付け。
- UTF-8 / BOM / Shift_JIS / UTF-16、引用符・セル内改行の読み込み。列の手動マッピング。
- 口座と名義の割り当て、名義別資産・年別/月別配当・利息の集計。
- 明細IDを使う再取り込み照合。IDなしは口座・名義・日付・内容・金額・出現順で照合。
- 振替・計算対象外・未来日を初期除外。配当、利息、税、元本払戻を区別し、手動で確認・変更。
- 保有資産の編集、年間配当単価、税区分、基準口数、入金予定月による今後12か月の配当予測。
- 月末積立・値上がり・増配・税引後配当再投資を分けた3条件の資産シミュレーション。
- ChatGPT向けMarkdown / 正規化JSON、名義・口座の仮名化、保有資産CSV、配当CSV。
- 任意のIndexedDB端末保存。復元用JSON、AES-GCM + PBKDF2（SHA-256 / 210,000回）暗号化バックアップ。
- デモは架空データ。実データとは分離され、デモ変更は保存しません。

## 取り込みの手順
1. 入出金CSVを選び、プレビューと列・名義を確認して取り込みます。複数ファイルは順番に確認します。
2. 「名義・保存設定」で口座を名義に結び付けます。CSVの名義はこの設定より優先されます。
3. 銘柄別管理には別途、保有資産のCSVまたはコピーした表が必要です。入出金だけから残高を推測しません。
4. 予測に必要な数量・年間配当単価・税区分を「ポートフォリオ」の編集から補います。不明は空欄、無配は0。
5. 「ChatGPTに相談」で内容を確認し、コピーまたはファイルを書き出します。

資産推移は「日付・資産合計」の家族全体履歴です。保有資産の残高と重複加算しません。各人の履歴を家族全体の履歴として混在させないでください。

### 保有資産CSV
アプリ内の「保有資産テンプレートCSV」を参照してください。評価額・取得金額・年間配当単価は円換算済みが扱いやすい形式です。外貨のまま取り込む場合は通貨と「1外貨あたり円」の換算レートが必要です。

取得額は総額が必要です。平均取得単価を総額として割り当てないでください。評価損益がある場合は評価額から取得総額を補完できます。1万口あたり分配金は配当基準口数10,000、株式は1を指定します。

デフォルトの取り込みは個別資産の追加・更新です。売却済み資産を自動削除しません。完全な残高一覧の場合だけ「口座ごと入れ替え」または「全件入れ替え」を選んでください。

## 重要な制約
- Money Forwardへの自動ログインや直接同期、株価・最新配当予想の自動取得はありません。
- XLS/XLSX/PDFの直接解析はしません。CSVへ保存するか、表を貼り付けてください。
- 配当はキーワードで仮分類します。銘柄名だけの明細は見落とし得ます。「すべての明細」で確認してください。
- 異なる口座・別IDに記録された同一配当は自動照合できません。証券口座と銀行の二重計上は手動除外してください。
- 実績はCSV記載の受取額です。税引前への逆算や二重の税引きはしません。
- 予測は入力された単価と数量による仮定。NISAは国内税ゼロとして試算し、外国源泉税・受取方法・手数料・税端数は別途確認が必要です。税率の初期値20.315%は変更可能です。
- シミュレーションは現金を含む表示対象総資産へ一律の値上がり率を適用。値上がり率は配当を含めず指定します。配当未設定分はゼロ補完した正確な全体予測ではなく、計算可能分のみの試算です。
- 月ごとの予測配当は指定入金月への均等配分。権利確定月ではありません。
- 相場予測や個別投資の推奨、税務申告用計算ではありません。

## プライバシー
依存CDN・解析タグ・外部フォント・通信APIはありません。`connect-src 'none'` のCSPを使用します。サーバーへ金融データを送信する処理はありません。ただしホスティングのアクセスログには通常のページアクセスが記録され得ます。

初期状態はメモリ内のみ。「この端末に保存」をオンにするとIndexedDBに平文保存されます。同じブラウザの利用者や同一オリジンの他スクリプトから読み取られる可能性があります。端末内保存は認証付き金庫ではありません。ブラウザの削除・容量制限に備えてバックアップが必要です。

暗号化バックアップはファイルにのみ適用されます。相談用仮名化は自由記述の相談文を置換しません。金額や日付からの再識別リスクもあるため、外部共有前に確認してください。CSV出力では数式として解釈される文字列をエスケープします。

## 開発・検証
Node.jsの外部パッケージは不要です。

```sh
node --test tests/mf-assets.test.cjs
python3 -m http.server 8080
# http://localhost:8080/mf-assets/
```

- `core.js`: CSV、正規化、照合、集計、予測、相談用出力の純粋関数。CommonJSからも読み込み可能。
- `app.js`: DOM、IndexedDB、バックアップ、画面操作。
- `style.css`: スマートフォン対応のレイアウト。
- `index.html`: 静的ページ。既存のリポジトリのルートページとは別アプリ。
