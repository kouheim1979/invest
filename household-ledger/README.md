# 家計コンパス 0.4

Money Forward ME本体とは独立した個人用CSVアプリ。ランタイム依存・外部送信なし。

## 操作

- CSVを読み込み、月／年を選択。期間カードを左右にスワイプすると、前後の期間と下部明細が連動します。左右ボタン・キーボード・年月入力も対応。
- カテゴリ、カレンダー日付、店舗をタップして下の明細を絞り込み。100件ずつ追加表示し、全明細まで確認できます。
- 専用分析：給与・賞与、食費・外食、教育費、店舗別年次推移、休日外食、資金移動・用途確認。
- 予算・分析設定・店舗名補正・給与区分補正は「端末に保存」。設定込みJSONバックアップで別端末へ移せます。

## データと推定の区別

- 元の日付、符号付き金額、費目、メモ、ID、計算対象、振替を保持。残高調整は収支から除外。
- 同一ID・同一口座・同一内容のみ再取込を除外。異なるIDの同日同額は候補にとどめ、同一IDの内容相違は要確認。
- 未収録の年月を飛ばさず「—／記録なし」。過去12暦月の平均は記録のある月だけを分母にし、実際の分母を表示。記録月があっても月全体の網羅を保証しません。
- 給与日初期値：2019年以前20日／2020年以降25日（変更可）。土日祝は前営業日へ調整。日付だけの判定は「賞与候補」。給与関係と確認できない入金やラクマ・立替精算は対象外。
- 食費分析は飲み会・明示的チャージを別枠に。元の費目は自動で書き換えません。
- 店舗は支出額、明細件数、利用日数を区別。同日同店舗名を1利用日とし、実際の来店回数・人数とは断定しません。返金のみの日は利用日数に含めません。
- 休暇期間はユーザーが設定した場合のみ。土日祝とは排他的に集計。
- 祝日判定2010〜2027年は内閣府ルール、2019年の特例、2020〜2021年移動に対応。対象外は祝日未確認。
  - https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html （確認2026-09-23）
- 振替・残高調整・元の集計除外行は保存していても通常収支に含めません。「対象外も表示」で確認可能。
- 取引CSVから現在残高・証券評価額は復元しません。資産画面は既存資産コンパスへ接続。

## 保存互換性・プライバシー

IndexedDB `household-ledger` v1 / store `d` を維持。旧 `tx` キーの保存を読み込み可能。新規保存は `bundle-v4` に明細・設定・予算を保存し、`tx` も維持。世代番号で別タブの保存競合を検出。旧予算 `hlbudget:YYYY-MM` も読み込みます。

CSVの取り込み後は自動保存し、失敗時は警告します（直近PR #24の動作を維持）。分析用補正や予算は「端末に保存」で確定します。CSVの再取込は追加方式。重複と断定できる同一IDの再取込は追加せず、未確定候補は保持。UTF-8/Shift_JIS対応。日付・金額・列数不正はファイル全体を中止し、既存データを維持。

CSV出力は表計算の数式インジェクションを防ぎ、保護列を使って再取込時に元の文字列へ戻します。JSON復元の予算値も検証します。レポジトリ・テスト・画面サンプルに個人の家計データを含めません。ローカル保存は暗号化ストレージではありません。データやバックアップの公開を避けてください。

## 検証

```sh
node --test tests/household-ledger/core.test.cjs
python -m pip install playwright==1.58.0
python -m playwright install chromium
python tests/household-ledger/browser.py
```

CIは架空データのみで、実際のタッチスワイプ、年月境界、カテゴリ・明細連動、1,000行超、CSV/JSON、IndexedDB保存・再読み込みを検証します。

`--offline` はネットワークなしでHTMLをChromiumへ直接投入する検証モード。オリジンが不透明なため実IndexedDB検証をスキップし、スキップを表示します。
