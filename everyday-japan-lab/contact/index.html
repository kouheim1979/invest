Report a correction or tool problem

Open a GitHub issue

This opens a public form on GitHub and may require a GitHub account. Nothing is submitted automatically. Include the page URL, what appears incorrect, the result you expected and a primary source if you have one. For a calculation problem, use non-sensitive example inputs.

Issues are public. Do not include personal contact details, payment information, health information or identifying photos. This development site does not yet offer a private enquiry channel.
