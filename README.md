# Portfolio Dashboard

Yahoo!ファイナンスのポートフォリオ画面を参考にした、iPhone向けの保有株一覧ダッシュボードです。

## 特徴

- 保有銘柄、保有数、取得単価を端末の `localStorage` に保存
- GitHub の公開ソースには個人の保有数・取得単価を保存しない
- 現在値・前日比を取得できた場合のみ表示（取得できない場合は推測しない）
- 評価額、評価損益、損益率、前日比を自動計算
- コード・銘柄名検索、値上がり/値下がり絞り込み、並べ替え
- JSONインポート/エクスポート
- 各銘柄からYahoo!ファイナンス個別ページへ移動
- iPhoneではカード表示、PCでは一覧表表示

## GitHub Pages

`main` への push で `.github/workflows/pages.yml` が GitHub Pages に自動デプロイします。

## データについて

保有データはブラウザ内にのみ保存されます。ブラウザデータを削除すると消えるため、必要に応じて「書出」でJSONバックアップを保存してください。
