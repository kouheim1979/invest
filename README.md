# Portfolio Dashboard

Yahoo!ファイナンスのポートフォリオ画面を参考にした、iPhone向けの保有株一覧ダッシュボードです。

## 特徴

- 保有銘柄、保有数、取得単価を端末の `localStorage` に保存
- GitHub の公開ソースには個人の保有数・取得単価を保存しない
- 現在値・前日比を取得できた場合のみ表示（取得できない場合は推測しない）
- 評価額、評価損益、損益率、前日比を自動計算
- コード・銘柄名検索、値上がり/値下がり絞り込み、並べ替え
- JSONインポート/エクスポート
- 各銘柄からYahoo!ファイナンス個別ページへ移動
- iPhoneではカード表示、PCでは一覧表表示

## GitHub Pages

`main` への push で `.github/workflows/pages.yml` が GitHub Pages に自動デプロイします。

## 株価の更新

- GitHub PagesではActionsが取得した保存株価を読み込みます。更新ボタンはActionsを起動しません。定期実行には遅延があります。
- Vercelに同じリポジトリを公開すると、画面から `/api/quotes` を呼び出し、その時点の配信株価を取得します。配信元による遅延があり、リアルタイムを保証するものではありません。
- GitHub Pagesの画面を引き続き使う場合は、公開済みVercelのAPI URLを `quotes-config.json` の `apiUrl` に設定します。現在は未設定です。保有データの保存先を変えずに接続できます。
- APIへ送るのは銘柄コードのみです。保有数・取得単価・名義は送信しません。
- APIと保存株価は並行して読み、古い価格で新しい価格を上書きしません。通信失敗・欠損時は前回値と元の時点を維持します。
- 株価時点と「保存株価」「更新失敗」を画面に表示します。取得できない前日終値を0円として扱いません。

## 取得額

一覧表とスマートフォンの各銘柄に取得額を表示します。「取得額・口座内訳」では銘柄全体、または選択した名義・証券・口座区分の内訳を表示します。口座内訳がなくても、登録済みの保有数と取得単価から取得額を表示します。明細の取得額がある場合は、その額を使って集計します。

## 口座区分の変更

「取得額・口座内訳」で明細ごとにNISA・特定・旧NISA・ジュニアNISA・一般・区分未判定を選び、「変更を保存」で確定できます。変更はこのブラウザに保存され、一覧・口座区分の絞り込みにも反映されます。「キャンセル」や背景クリックでは保存しません。JSONを再読込すると、口座区分も読み込んだ内容で置き換わります。

## 検証

`node --test tests/portfolio.test.cjs` で株価更新・フォールバック・取得額・口座絞り込み・口座区分の変更と保存の回帰を確認できます。

## データについて

保有データはブラウザ内にのみ保存されます。ブラウザデータを削除すると消えるため、必要に応じて「書出」でJSONバックアップを保存してください。

## チャートとiPhoneウィジェット

各銘柄の「チャート」から1か月・3か月・1年の日足と平均取得単価を確認できます。スライダーで日付を選べます。Yahoo Financeの配信日足をActionsで取得し、銘柄ごとに最大1時間に1回更新します。失敗時は最終成功データを日時ごと保持し、データのない銘柄には外部チャートのリンクを表示します。追加銘柄は現在の株価取得対象に入っていない場合、履歴も未取得です。

「ウィジェット」からScriptable用コードと設定手順を開けます。iPhoneの小・中・大サイズに対応し、銘柄コードをParameterで指定します。公開済み保存株価のみを取得し、失敗時は端末キャッシュを表示します。保有数・取得額や口座区分の自動同期はありません。更新頻度はiOSに依存します。iPhoneへの追加は利用者側で行います。

`node --test tests/*.test.cjs` で回帰テストを実行します。
