# 配当の10年

持ち株アプリ `app-v3.html` の上部「配当10年」、または各銘柄の「配当10年」から `dividends.html` を開きます。元の保有データ・株価・チャート・口座内訳の機能は変更しません。

## 銘柄の配当推移

- 公開配当情報の直近10期（約10年）を、決算期ごとの棒グラフ・一覧表で表示します。
- 1株当たり年間配当、表示期間の1株配当合計、前年同期比、増配・減配・据置、年平均増配率を確認できます。
- 10個の年次観測点の端点間は通常9年間です。年平均増配率はこの実際の年数で計算します。開始または終了が0円、欠損の場合は計算しません。
- 株式分割・併合についてはYahoo!ファイナンスの「年間配当（調整後）」をそのまま使います。異なる株数単位の中間・期末配当を足し直したり、さらに二重調整したりしません。
- 会社予想は別枠に表示し、実績のグラフ・合計・増配率には含めません。進行中の期の部分実績も完成した年次実績として扱いません。
- 出典リンクと銘柄ごとの取得日時を表示します。欠損は「未取得」、明示された無配は0円です。取得失敗時は最終成功の値と日時を維持します。
- 「現在の保有株数で換算する」は、現在の名義・証券会社・口座区分で絞り込んだ株数を固定して掛ける税引前の参考値です。過去の実受取額ではありません。
- 銘柄名や株数は、元の持ち株アプリと同じブラウザの保存データを利用します。

## 実際の受取配当

- 選択した最終年までの10年間を、受取日基準・暦年で表示します。今年を含める場合は今年が途中の値であることを明記します。
- 税引前／税引後、名義、証券会社、受取時の口座区分、銘柄、通貨で絞り込めます。旧NISA・ジュニアNISAも独立した区分です。
- 年別合計・期間合計・明細数を表示し、年の棒や表をタップすると当該年の入金記録を確認できます。
- 過去の入金記録は自動生成しません。未登録の年を0円とせず、金額が分かる登録済み明細だけを集計します。記録が一部欠けた年の数値も全額の保証ではありません。
- 手入力、所定形式のCSV・JSON読込に対応します。読み込む前に追加件数と重複件数を確認できます。
- 金額はgross（税引前）、tax（税額）、net（税引後）です。二つが分かれば残りを差引計算できますが、税率から推測はしません。NISAというだけで税額0円を仮定しません。
- 異なる通貨は合算せず、通貨ごとに集計します。現在の保有口座の変更で昔の受取記録を書き換えることもありません。
- 配当記録は `kouheim_portfolio_dividends_v1` に端末内保存します。株の保有データとは別です。保有数・取得額・名義・入金記録をGitHubへ送信しません。
- 全記録のJSONバックアップと、表示条件に合うCSVの書出ができます。ブラウザデータ削除前や端末移行前にはバックアップしてください。

## 受取配当のファイル形式

JSONは `{ "schemaVersion": 1, "receipts": [...] }`、または明細の配列を読み込めます。

CSVの列名：`id,date,symbol,name,owner,broker,accountType,currency,gross,tax,net,note`

`date` と `symbol`、および `gross` または `net` が必要です。日付はYYYY-MM-DD形式。日本株の4桁コードは東証の`.T`を補います。札幌銘柄などは`.S`を明示してください。証券会社独自のCSVを無条件に読み込む機能ではありません。テンプレートの列名に合わせてから読み込んでください。

明細IDなしの場合は日付・銘柄・名義・証券・口座区分・通貨・金額が同じ明細を重複とします。同条件の別入金は異なるidを指定してください。同一idで金額などが異なる場合は、上書きせず読込を止めます。

## 公開履歴の更新

`.github/workflows/dividends.yml` で日次取得します。取得対象は公開済み `quotes.json` の銘柄コードです。新しい銘柄を端末へ追加しただけではサーバーの履歴取得対象へ追加されません。未取得の場合はYahoo!ファイナンスの確認リンクを表示します。

画面の「データ再読込」は保存済み公開データを読み直す操作であり、取得ワークフローを起動する操作ではありません。定期実行・配信元の更新には遅延があります。

## 検証

`node --test tests/*.test.cjs` に、欠損・明示的な無配・予想除外・分割調整列・税額不明・10年間集計・通貨分離・重複読込・不正日付・CSVの回帰テストを含みます。

`tests/dividends-browser.py` は架空の保有数と入金額だけで、Chromium／WebKit、320〜1280px、Apple株価風、読込・再読込・保存・名義別換算・元アプリからの遷移を検証します。WebKitでの検証はiPhone実機での動作保証とは異なります。
